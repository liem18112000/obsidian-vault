# Code review agreement

> [!info] Imported from Confluence
> Space **Helios** · updated 2019-06-21 · [open original](https://axonivy.atlassian.net/wiki/spaces/Helios/pages/38196092517/Code+review+agreement)
> Relevance 0.852 · topic `programming`

1. PR: take case basic checks (CSS, format,.....)

2\. Code Review should focus on logic flows / main features.

3\. Explain the idea before sharing.

4\. Mention common methods/resources.

5\. Timebox per person: \<= 5mins/member. Set priority for major things/topics

6\. Story turn

7\. Limit joking

8\. Reduce personal emotion. Stop & note the point to discuss later.

9\. No bully

10\. Potential issue --\> write note & raise after a member finished the explanation. Don't interrupt ( bring notes & pen)
