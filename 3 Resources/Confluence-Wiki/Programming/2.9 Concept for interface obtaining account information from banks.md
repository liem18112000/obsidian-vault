# 2.9 Concept for interface obtaining account information from banks

> [!info] Imported from Confluence
> Space **GRAVITY** · updated 2019-08-13 · [open original](https://axonivy.atlassian.net/wiki/spaces/GRAVITY/pages/14516505975/2.9+Concept+for+interface+obtaining+account+information+from+banks)
> Relevance 0.711 · topic `programming`

<span style="letter-spacing: 0.0px;">At the moment with most banks, we will have a service to get some information from the core banking system like account number, customer number and so on. One purpose of these numbers is to be printed on documents. To get the different numbers from the bank into our system we would use an interface.</span><span style="letter-spacing: 0.0px;">The interface is likely to be different for each bank. In addition, we found out that these interfaces are not ready on the side of Hypi. But we don't want to wait until the service is ready. That's why the idea is to implement a generic solution first, which can be replaced easily with the real credentials once they are available.</span>
