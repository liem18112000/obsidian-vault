# Ways to access - Klara company with subscription

First of all, we need the **subscription (widget code: public_api_print_partner)** for the company:

Go to admin page → Menu subscription → add new → select company then add the subscription **public api print partner**


![[47396782081-image-20230606-025451.png]]



Then, authorize the request with these options on Klara public api:
