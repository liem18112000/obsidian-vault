## Checklist

- ## Install docker, kubectl (10mins)

- ## Containerize javaee hello world application with wildfly 10 (45mins)

  - ## Create dockerfile

  - ## Run in local machine

- ## Push image to gcloud (1h)

  - ## Config credential that can push docker image to gcloud

- ## Deploy image to kubernetes and export to internet (1h)

  - ## Use kubectl deploy image or munual deploy

  - ## Expose to service load balancer that can be access from the internet

  - ## Use kubectl check log application

- ## After done the above steps enhance application with database connection (2h)
