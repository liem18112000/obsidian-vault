# 14. Deploy openshift cluster monitoring

> [!info] Imported from Confluence
> Space **AII** · updated 2018-04-11 · [open original](https://axonivy.atlassian.net/wiki/spaces/AII/pages/3535260633/14.+Deploy+openshift+cluster+monitoring)
> Relevance 0.734 · topic `infra`

This section will deploy prometheus to collect cluster metric. Prometheus will use metrics provided by <a href="https://github.com/google/cadvisor" class="external-link" rel="nofollow"><span>cAdvisor</span></a> via <a href="http://kubernetes.io/docs/admin/kubelet" class="external-link" rel="nofollow">kubelet</a> service (runs on each node of Kubernetes cluster by default) and via <a href="http://kubernetes.io/docs/admin/kube-apiserver" class="external-link" rel="nofollow"><span>kube-apiserver</span></a> service only. And grafana for Visualize 

### Deploy Prometheus

oc project openshift-infra   \#choose a namespace  
oc adm policy add-cluster-role-to-user cluster-reader -z default  \#for the default account give cluster wide read permission so prometheus can read metrics  
oc adm policy add-scc-to-user anyuid -z default  allow containers with root USER 

oc new-app prom/prometheus     \#deploy latest prometheus  
oc create -f <a href="https://raw.githubusercontent.com/debianmaster/openshift-examples/master/promethus/prom-configmap.yml" class="external-link" rel="nofollow">https://raw.githubusercontent.com/debianmaster/openshift-examples/master/promethus/prom-configmap.yml</a>     \#mount this configmap at at /etc/prometheus/prometheus.yml  

  
oc volume dc/prometheus --add --name=prom-k8s -m /etc/prometheus -t configmap --configmap-name=prom-k8s  \#set rules inside prom

### Deploy Grafana

Grafana will deploy in persistent storage

git clone: <a href="https://github.com/wkulhanek/docker-openshift-grafana.git" class="external-link" rel="nofollow">https://github.com/wkulhanek/docker-openshift-grafana.git</a>

oc create -f grafana.yaml  
oc new-app grafana -p VOLUME_CAPACITY=4Gi

#### Configure a Grafana Data Source

Log into Grafana using the Route provided in the Template and using default account `admin` with password `admin`(maybe it would be a good idea to change the password after this…).

On the Home Dashboard click Add data source

Use the following values for the datasource Config:

- Name: `DS-Prometheus`

<!-- -->

- Type: `Prometheus`

<!-- -->

- Url: <a href="http://prometheus:9090/" class="external-link" rel="nofollow">http://prometheus:9090</a> (if your Prometheus service is called `prometheus` and is in the same project)

<!-- -->

- Access: proxy

Click `Add`

Click `Save & Test`. You should see a message that the data source is working.
