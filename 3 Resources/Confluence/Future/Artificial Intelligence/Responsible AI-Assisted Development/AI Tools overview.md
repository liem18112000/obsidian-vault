# AI Tools overview

*Confluence source · Future › Artificial Intelligence › Responsible AI-Assisted Development · [view original](https://axonivy.atlassian.net/wiki/spaces/FUT/pages/48916201613/AI+Tools+overview) · updated 2026-03-12*

This page is an overview of AI-tools, presents which tool is used for what.

Guide to fill the table

- Tool name: input any AI tool that your team is using. In the case the tool is special, please note down short description. See OpenRouter as example.

- Tool type: Chat Interface / IDE Extension / AI-Native IDE / Service. If those categories do not match with your tool, feel free to but any type you think. We will refine it later.

- Current Licensing:

  - Use the license term of the tool.

  - In the case your team has one member uses Free license and another one uses Pro license → input Free, Pro to the column.

- Purpose Category:

  - scroll down and read the section “Guidance for Purpose Category“ to understand what they are.

  - One tool can be used for many purposes. Let’s take Cursor for example. Team A uses Cursor for Design & Ideation, Analysis / Non-Coding and Prototyping / PoC. And team B uses Cursor for Prototyping / PoC and Production Coding → final input are merged: Design & Ideation, Analysis / Non-Coding, Prototyping / PoC, Production Coding.

- **Please add your tools to the list if it is not existed.**

### Guidance for Purpose Category

|  |  |
|----|----|
| **Category Name** | **Focus** |
| **Production Coding** | Code intended for commit to the main codebase. |
| **Prototyping / PoC** | Code generated for experimentation that will be reviewed before production use. |
| **Analysis / Non-Coding** | Analyzing or debugging existing code/logs, generating documentation, etc. |
| **Design & Ideation** | Research, architecture, system design, or general knowledge gathering. |

### **Use of Artificial Intelligence (AI) at ePost**

**Principle: Liberal and Responsible AI Usage**

**ePost** promotes the meaningful use of artificial intelligence in everyday work. AI is intended to support you in working more efficiently and with higher quality. Use is **permitted**, provided that information security, data protection are maintained.
