# Liem Doan Plan

*Confluence source · Team Kepler › Training Plan · [view original](https://axonivy.atlassian.net/wiki/spaces/TK/pages/48762880010/Liem+Doan+Plan) · updated 2025-10-24*

This plan gives you some overviews about how to set up your working device, know the most important people, and put you in the situation of being able to contribute as efficiently as possible.

Read through, if you have any questions, just contact ***@Scrum Master***

## First 5 days

**Target: Get to know development teams, PO, processes, and working environment in Vietnam**

- Read your 10-day plan and feel free to edit as you see fit, ask ***@Scrum Master ***if you have any questions
- Set up some communication tools, and spaces and ask ***@Scrum Master***** **to connect you to related people and channels
  - MS Teams 
  - Discord
  - Slack ([luz-axonivy.slack.com](http://luz-axonivy.slack.com))
  - Outlook 
  - Zoom
  - Jira ([https://jira.axonivy.com/confluence](https://jira.axonivy.com/confluence))
  - Confluence
- Setup technical environments for your device with the following tools:
  - Java 8 (Only setup JDK)
  - Java 11 (Only setup JDK)
  - Java 17 (Only setup JDK)
  - Eclipse: [http://www.eclipse.org/downloads](http://www.eclipse.org/downloads) or **IntelliJ** or **Visual Studio Code** (Depending on yourself)
  - Maven: [https://maven.apache.org/download.cgi](https://maven.apache.org/download.cgi)
  - Git: [https://git-scm.com/downloads](https://git-scm.com/downloads)
  - WinSCP: [https://winscp.net/eng/download.php](https://winscp.net/eng/download.php)
  - Putty: [https://putty.org/](https://putty.org/)
  - Ivy Designer 9: [http://developer.axonivy.com/download/](http://developer.axonivy.com/download/) or reference at here [Training hub#\uD83D\uDCD8-For-new-comer](https://axonivy.atlassian.net/wiki/spaces/LUZ/pages/47355854953/Training+hub#%5CuD83D%5CuDCD8-For-new-comer) (**Please ignore it and will be set up when starting setup KLARA application**)
  - Wildfly (**please ignore it and will be set up when starting setup KLARA application**)
  - Postgress database 9.5
- Let ***@Scrum Master ***introduce you about working processes:
  - \#team
  - @PO
  - All KLARA teams
  - Slack channels
  - Confluent page (Kepler and Klara)
  - The meeting in KLARA and team (daily, cross daily, review, planning 1, planning 2, retrospective meeting, joint retrospective meeting, prepare for the review meeting).
  - Permission for current servers (Jenkins, Klara Local, Klara Dev, Klara Staging).
  - Agreement of the team (cross test, DoD, add all team members to pull request and at least a haft of members approve, no new sonar bug, fund).
  - Scrum process, self-organize in the team
- Let **@Scrum Master / Team** introduce you to the KLARA application:
  - KLARA application
  - Features in team
- Let **@Scrum Master / Team** introduce you about:
  - Ivy, JSF (please look at the ivy video training K:\AxonFintech\Training\Axon.ivy\videos)
  - Back-end (MicroProfile, Service, Rest resource, Unit Test, Integration test)
  - Docker, docker-compose, and Kubernetes.
- Practice GCP to understand how to work with GCP ([GCP Practice](https://axonivy.atlassian.net/wiki/display/TK/GCP+Practice)).
- Setup luz-docs ([luz_docs: setup very first run](https://axonivy.atlassian.net/wiki/spaces/LUZ/pages/20525310886/luz_docs+setup+very+first+run)) on your local and use postman to:
  -  Create document
  - Get all documents and specific document
  - Search query document
  - Search facet document
  - Download a file
  - Create folder
  - Get all folders and specific folder
  - Search folder
- Setup luz-audit on your local and use postman
- Setup luz-storage on your local and use postman
- The following feelings after two weeks of training together with the team:
  - Feelings about the meeting in KLARA/team. What and how to enhance this session?
  -  Feelings about the sharing/training meeting, What and how to enhance this session?
  - Feeling about the working process in team/KLARA.
- Please reference more information at the link here: [Training hub](https://axonivy.atlassian.net/wiki/spaces/LUZ/pages/47355854953/Training+hub) 

## First 10 days

**Target: Get used to working environment, application and implementation. **

- Axon Ivy ([Klara Ivy on-boarding](https://axonivy.atlassian.net/wiki/display/LUZ/Klara+Ivy+on-boarding))
- JSF
- Java EE (Restful, JPA, Unit Test with Powermock and Mockito, Integration Test with Arquillian, ...)
- MicroProfile
- Set up the KLARA application in your local machine via this confluence page [KLARA Setup Workspace IVY9](https://axonivy.atlassian.net/wiki/spaces/TK/pages/30677827233/KLARA+Setup+Workspace+IVY9). **Note:** Be proactive to contact KLARA teammates if you get trouble while setting up and be proactive to update the confluence page if necessary.
- Make sure that you can run these following main features below. Contact the ***@RelatedPerson*** if you need help
  - Create a new company
  - Create employee
  - Create customer/partner
  - Create Article
  - Create order in order management
  - Setup accounting
  - Inventory
- [Git strategies](https://axonivy.atlassian.net/wiki/display/NEXT/Git+Flow+installation+instruction)
- Architecture of Klara system
- Have to know key features of your current team and how the team works
- Can attacks simple tickets in pair or independently
