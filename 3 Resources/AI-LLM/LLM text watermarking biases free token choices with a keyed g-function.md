# LLM text watermarking biases free token choices with a keyed g-function

Claude's text watermark (rolling out globally from **August 2026**, driven by **EU AI Act** transparency obligations) works by biasing an already-free choice rather than by adding anything to the text.

The mechanism, **SynthID-Text** (DeepMind, *Nature* 2024; descended from Scott Aaronson's 2022 proposal):

- At each token, several candidates are **equally good**. Normally one is picked by a coin flip.
- Instead a **g-function** — a pseudo-random function seeded by a secret **key plus the preceding `ngram_len` tokens** — scores each candidate.
- **Tournament sampling** runs the candidates through bracket rounds; higher g-values advance; the winner is emitted.
- Detection recomputes the g-values with the key and takes the **mean g-value**. Watermarked text scores measurably high; unwatermarked text averages out.

Two properties that decide where it works:

- **Non-distortionary** — it preserves the model's output distribution *in expectation*, so quality is not traded for detectability. Larger `ngram_len` → more detectable.
- **It needs free choices to hide in.** Prose, creative writing, code comments and translations have thousands of low-stakes word choices. **Executable code, exact syntax, precise facts, and light proofreading do not** — so those are not watermarked. A file's bytes have nowhere to hide a signal at all, which is why binary content uses **C2PA Content Credentials** (a signed provenance manifest) instead.

Worth knowing: the watermark **carries no identifying information** — it is not traceable to a person, org, or conversation. It answers "was this generated by this model?", never "by whom?".

Related distinction from C2PA: **hard binding** is a cryptographic hash of the bytes (exact, breaks on any edit) vs **soft binding** — a watermark or fingerprint that survives re-encoding and lets provenance be re-matched after the manifest is stripped (*Durable Content Credentials*).
